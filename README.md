# malta-para-brasileiros
Meu projeto individual será o desenvolvimento de um site chamado Malta Experience, voltado para brasileiros que desejam morar em Malta ou que já vivem no país. A proposta é reunir informações práticas sobre o planejamento da viagem, os primeiros passos após a chegada e a adaptação à rotina local, utilizando também experiências reais para ajudar outras pessoas a se prepararem melhor para essa vivência. - Sptech
